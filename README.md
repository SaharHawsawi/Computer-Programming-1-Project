# Computer-Programming-1-Project
a beginner-friendly Java project developed as part of the Programming 1 course. It combines two basic operations: printing numbers with increments of 5 and playing a number-guessing game using a randomly generated number.

The project demonstrates how basic Java concepts, such as methods, loops, conditional statements, user input, and random number generation, can be combined to create an interactive console-based application.
# About the Project
Java console application designed to practice and apply the fundamental concepts introduced in Programming 1.

The application consists of two main functionalities:
1. Incremental Number Generation : Users enter a starting integer and an ending integer. The program validates the input and displays a sequence of numbers, increasing by 5 with each iteration.
2. Random Number Guessing : The program generates a random integer between 1 and 100 and compares it with the number entered by the user. It then provides feedback indicating whether the guess is correct, too low, or too high.

By combining these functionalities, the project provides a practical introduction to developing interactive programs using Java.
# Project Objectives
The main objectives of this project are to:
* Apply fundamental Java programming concepts in a practical application.
* Develop methods to organize and separate program functionality.
* Practice using loops to repeat instructions and generate number sequences.
* Implement conditional statements to validate input and compare values.
* Understand how to read user input using the Scanner class.
* Explore random number generation using the Random class.
# Features
1.  Incremental Number Generation : Generate a sequence of integers starting from a user-defined value and increasing by 5 each time.
* Accepts a starting number and an ending number.
* Continues while the current number does not exceed the ending value.
* Displays each generated number on a separate line.
2. Input Validation : Ensures that the starting number is smaller than the ending number.
* Checks whether the starting number is greater than or equal to the ending number.
* Displays an error message when the input does not satisfy the required condition.
* Requests new values until the condition is satisfied.
3. Random Number Generation : Generates a random integer between 1 and 100 using Java’s Random class.
4. Number Guessing Feedback : Compares the user’s input with the generated random number and displays an appropriate response.
* Correct Guess: Displays a congratulatory message.
* Too Low: Indicates that the entered number is smaller than the generated number.
* Too High: Indicates that the entered number is greater than the generated number.
# How It Works
The program executes its operations in the following order:
1. Displays the application name.
2. Requests two integers from the user: a starting value then an ending value.
3. Validates the entered values.
4. Generates and displays a sequence of numbers with increments of 5.
5. Requests a number between 1 and 100.
6. Generates a random number within the specified range.
7. Compares the user’s number with the generated number.
8. Displays the corresponding result.
# Technologies Used
* Java — The primary programming language used to implement the application.
* Java Scanner — Used to read integer input from the user.
* Java Random — Used to generate a random integer for the guessing game.
